# Text-Summarizer
Text Summarizer Web Application

A simple and stylish Flask web application that summarizes long text content. Users can upload `.txt`, `.pdf`, or image files (like `.jpg`, `.png`) to extract and summarize text using NLP techniques.

Features

Upload and summarize text from `.txt` and `.pdf` files
Extract text from images using OCR (pytesseract)
Uses NLTK-based summarization logic
Clean UI built with Bootstrap and custom CSS
Fast local execution using Flask
No external API calls required

Tech Stack

- Frontend: HTML, CSS, Bootstrap
- Backend: Python, Flask
- NLP: NLTK
- OCR: pytesseract, Pillow
- File Handling: PyPDF2
